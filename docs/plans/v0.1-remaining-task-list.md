# v0.1: the remaining tasks

A companion to `v0.1-status.md`. Each task below can be picked up alone by a fresh agent. A task whose "Depends on" tasks are all done may start; two tasks may run at once only if neither lists the other under "Collides with". Sizes are estimates from the pace of 2026-11-24: S is a few hours of one session, M about a day with one review look, L several days. Tasks marked **yours** are the author's own and no agent can do them.

## How to work a task

- **Start from** the branch the task names, in a worktree of your own, on a new branch `task/T0xx`. Never work in the main checkout, never move the local `main` ref, never push.
- **Read first** `AGENTS.md` and `CLAUDE.md`, then what the task names. The lanes' notes of 2026-11-24 are not in the repository: they are copied, on the author's machine, to `.claude/v01-notes/` under the main checkout, which is `$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")/.claude/v01-notes`. Each lane's hand-over opens with a short "Where … stands".
- **Build** in small commits, each with a test that fails without it. Commit no generated file and do not vendor the viewer.
- **Test** what you touch as you go; one whole `scripts/regen` and `scripts/verify fast --workers 2` before you hand over. Every run of loom outside the tests has HOME and the XDG folders in a scratch folder.
- **Hand over** in a few lines at the end of the task's branch description or in a note beside the others: what is done, what is not, what was run.
- **Review:** where a task says "Review: yes", one look by a fresh agent with a narrow bar before it lands; otherwise the diff is read.
- **Landing a finished task** is its own small step: merge onto the integration branch, `scripts/regen`, vendor the viewer if viewer source changed, `scripts/verify full --workers 2`, push, then read GitHub's CI for that head. A red job there is a failed lane. This Mac's lane runs Python 3.13 on a case-insensitive disk with its own fonts; CI runs Linux under 3.11 to 3.13.

Until T002 is done, the integration branch is `library-web`, which holds everything on `main` and the redesigned library and views besides. After T002 it is `main`.
